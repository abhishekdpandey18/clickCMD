# Changelog

## [1.2.0] - 2026-08-13

### Added
- Favorites for individual commands.
- Favorites-only dashboard filter.
- Persistent command history.
- Command History viewer and clear-history action.
- Automatic migration for older configuration files.
- Application version shown in the dashboard.

### Improved
- GitHub-ready project documentation and test coverage.

## [1.0.0] - 2026-08-13

### Added
- Initial Command Center release.
- Custom command dashboard.
- Command editor.
- Categories.
- Search.
- Command output panel.
- Terminal execution.
- Import/export.
- Backup/restore.
- Dark/light themes.
- Keyboard shortcuts.
- Safety confirmation for destructive commands.
- GitHub issue templates and test suite.
